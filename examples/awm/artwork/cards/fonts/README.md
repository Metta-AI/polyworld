# Grenze

Grenze combines Roman and blackletter influences in clear letterforms. Cards
use the Semibold weight for titles and numbers, and Regular for rules text.

Original, unmodified static font files are bundled from the designer's official
repository: https://github.com/Omnibus-Type/Grenze/tree/master/fonts/ttf
