# Card artwork generation

Mode: default built-in `image_gen.imagegen` tool. Each asset was generated independently with one call, visually inspected, and copied into this project from the built-in output directory. Original generated images remain in place. The artwork contains no frame, text, cost badges, or stat icons, so card composition stays separate.
